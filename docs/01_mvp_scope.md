# MVP 범위

## MVP 목표

지도에서 흡연/금연 관련 장소를 찾고, 장소에 대한 사용자 반응과 댓글을 남길 수 있는 최소 기능을 제공한다.

## 포함 기능

### 인증

- 회원가입
- 로그인
- 이메일 중복 확인
- 닉네임 중복 확인
- JWT Access Token 인증
- 로그아웃은 서버 API에서 HttpOnly accessToken Cookie 만료로 처리

### 장소

- 현재 위치 기준 1km 반경 장소 마커 조회
- 지도 bounds 기준 장소 마커 조회
- 장소 상세 요약 조회
- 장소 등록
- 장소 삭제
- 상세 요약 조회 시 조회수 증가

### 댓글

- 댓글 목록 조회
- 회원 댓글 작성, 수정, 삭제
- 비회원 댓글 작성, 수정, 삭제
- 비회원 댓글은 작성 시 비밀번호를 받고, 수정/삭제 시 비밀번호로 검증

### 반응

- 회원 좋아요/싫어요/취소
- 비회원 좋아요/싫어요/취소
- 한 시간대 안에서는 기존 반응 row를 수정
- 다음 시간대에는 새 반응 row 생성 가능
- 좋아요/싫어요 수는 누적 집계하되 `CANCELED`는 제외

## 제외 또는 후순위 기능

- Refresh Token
- 서버 측 로그아웃 토큰 블랙리스트
- 관리자 페이지
- 신고/검수 워크플로우
- 장소 수정 API
- 이미지 업로드
- 푸시 알림
- 복잡한 마커 클러스터링

## MVP 구현상 주의

- 장소 삭제는 hard delete cascade다.
- 개별 댓글 삭제는 soft delete다.
- nearby/bounds는 마커 표시용 기본 정보만 내려준다.
- 장소 상세 정보는 마커 클릭 후 summary API로 조회한다.
