# 사용자 / 권한 정책

## 사용자 유형

| 유형 | 설명 |
| --- | --- |
| 비회원 | 로그인하지 않은 사용자 |
| 회원 | JWT Access Token으로 인증된 사용자 |
| 관리자 | MVP 범위 밖 |

## 인증 정책

- 회원 API는 HttpOnly `accessToken` Cookie가 필요하다.
- 서버는 JWT를 검증하고 현재 사용자 ID를 추출한다.
- 토큰이 없으면 비회원 요청으로 처리 가능한 API만 사용할 수 있다.
- 토큰이 존재하지만 잘못되었으면 비회원으로 조용히 처리하지 않고 401로 응답한다.
- 서버는 로그인 세션을 저장하지 않는다.
- 로그아웃은 서버 API에서 HttpOnly accessToken Cookie를 만료시키는 방식으로 처리한다.

## 장소 권한

| 기능 | 비회원 | 회원 |
| --- | --- | --- |
| nearby 조회 | 가능 | 가능 |
| bounds 조회 | 가능 | 가능 |
| 상세 요약 조회 | 가능 | 가능 |
| 장소 등록 | 불가 | 가능 |
| 장소 삭제 | 불가 | 본인이 등록한 장소만 가능 |

장소 삭제 시 장소, 해당 장소의 댓글, 해당 장소의 반응은 모두 hard delete한다.

## 댓글 권한

| 기능 | 비회원 | 회원 |
| --- | --- | --- |
| 댓글 목록 조회 | 가능 | 가능 |
| 댓글 작성 | 가능 | 가능 |
| 댓글 수정 | 본인 비밀번호 검증 시 가능 | 본인 댓글만 가능 |
| 댓글 삭제 | 본인 비밀번호 검증 시 가능 | 본인 댓글만 가능 |

- 회원 댓글은 `/comments/member` 경로를 사용한다.
- 비회원 댓글은 `/comments/guest` 경로를 사용한다.
- 비회원 댓글은 `displayNickname`, `guestPassword`, `content`를 받는다.
- 비회원 댓글 비밀번호는 해시로 저장한다.
- 개별 댓글 삭제는 soft delete다.

## 반응 권한

| 기능 | 비회원 | 회원 |
| --- | --- | --- |
| 좋아요 | 가능 | 가능 |
| 싫어요 | 가능 | 가능 |
| 취소 | 가능 | 가능 |

- 회원 반응은 `/reaction/member` 경로를 사용한다.
- 비회원 반응은 `/reaction/guest` 경로를 사용한다.
- 비회원 반응은 `X-Guest-Key` 헤더가 필수다.
- `X-Guest-Key`는 프론트엔드가 UUID 등으로 생성하고 보관한다.
- 서버는 `X-Guest-Key` 원문을 저장하지 않고 SHA-256 해시만 저장한다.
- 같은 시간대에는 `place_id + 사용자 식별자 + reaction_hour_key` 기준으로 하나의 row만 허용한다.
- 같은 시간대 안에서 같은 반응을 다시 보내면 `CANCELED`로 변경한다.
- 같은 시간대 안에서 다른 반응을 보내면 요청한 반응으로 변경한다.
- 다음 시간대에는 새 row 생성이 가능하다.
