# 기능 명세서

## Auth

| ID | 기능 | 사용자 | 설명 |
| --- | --- | --- | --- |
| AUTH-01 | 회원가입 | 비회원 | 이메일, 비밀번호, 닉네임으로 회원 생성 |
| AUTH-02 | 로그인 | 비회원 | 이메일/비밀번호 검증 후 JWT Access Token 발급 |
| AUTH-03 | 이메일 중복 확인 | 비회원 | 회원가입 전 이메일 사용 가능 여부 확인 |
| AUTH-04 | 닉네임 중복 확인 | 비회원 | 회원가입 전 닉네임 사용 가능 여부 확인 |
| AUTH-05 | 로그아웃 | 회원 | 서버 API에서 HttpOnly accessToken Cookie 만료 |

## Place

| ID | 기능 | 사용자 | 설명 |
| --- | --- | --- | --- |
| PLACE-01 | 현재 위치 기준 주변 장소 조회 | 전체 | 현재 위치 기준 1km 안의 장소 마커 조회 |
| PLACE-02 | 지도 bounds 기준 장소 조회 | 전체 | 현재 지도 화면 안의 장소 마커 조회 |
| PLACE-03 | 장소 상세 요약 조회 | 전체 | 마커 클릭 후 바텀시트에 표시할 상세 요약 조회 |
| PLACE-04 | 장소 등록 | 회원 | 지도 중앙 핀 좌표 기준 장소 등록 |
| PLACE-05 | 장소 삭제 | 회원 | 본인이 등록한 장소와 하위 댓글/반응 hard delete |

## Comment

| ID | 기능 | 사용자 | 설명 |
| --- | --- | --- | --- |
| COMMENT-01 | 댓글 목록 조회 | 전체 | 장소별 댓글 목록 cursor 기반 조회 |
| COMMENT-02 | 회원 댓글 작성 | 회원 | 로그인 사용자가 댓글 작성 |
| COMMENT-03 | 비회원 댓글 작성 | 비회원 | 닉네임, 비밀번호, 내용으로 댓글 작성 |
| COMMENT-04 | 회원 댓글 수정 | 회원 | 본인 회원 댓글 수정 |
| COMMENT-05 | 비회원 댓글 수정 | 비회원 | 비밀번호 검증 후 비회원 댓글 수정 |
| COMMENT-06 | 회원 댓글 삭제 | 회원 | 본인 회원 댓글 soft delete |
| COMMENT-07 | 비회원 댓글 삭제 | 비회원 | 비밀번호 검증 후 비회원 댓글 soft delete |

## Reaction

| ID | 기능 | 사용자 | 설명 |
| --- | --- | --- | --- |
| REACTION-01 | 회원 반응 처리 | 회원 | 좋아요, 싫어요, 취소 처리 |
| REACTION-02 | 비회원 반응 처리 | 비회원 | X-Guest-Key 기준 좋아요, 싫어요, 취소 처리 |
| REACTION-03 | 시간대별 누적 반응 | 전체 | 같은 사용자도 다음 시간대에는 새 반응 row 생성 가능 |
| REACTION-04 | 현재 반응 상태 조회 | 전체 | summary 응답의 `myReactionType`으로 현재 시간대 반응 상태 표시 |

## Map Marker

| ID | 기능 | 설명 |
| --- | --- | --- |
| MAP-01 | nearby 마커 조회 | `GET /api/places/nearby`, 1km, 최대 100개, 거리순 |
| MAP-02 | bounds 마커 조회 | `GET /api/places/bounds`, 최대 100개, 최신 등록순 |
| MAP-03 | 마커 클릭 상세 조회 | `GET /api/places/{placeId}/summary` |

## 후순위

- 장소 수정
- 신고/검수
- 관리자 기능
- 이미지 업로드
- refresh token
- 서버 측 로그아웃/토큰 블랙리스트
- 마커 클러스터링
